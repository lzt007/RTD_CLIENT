# 2026-10-31 内置资源免下载验证

## 根因及修正

原始 AssetBundleLoader.Update 按 GetURL()/GetVersion() 调用 Caching.IsVersionCached。编号大于 0 且命中时跳过下载；编号 0 始终调用 LoadFromCacheOrDownload，但该 API 在命中缓存时本地读取。完成后用 IsVersionCached 复核并 MarkAsUsed。

原备份 __info 第二行记录 2014 年最后使用时间。AssetBundleLoader.Awake 会设置 Caching.expirationDelay，因此复制原始元数据后会被当作过期资源。正常下载后，同一缓存条目的第二行更新为当前 Unix 时间。设备文件描述符证明引擎读取 Application.persistentDataPath/UnityCache/Shared 下对应的 CustomAssetBundle。

修正释放路径为 Application.persistentDataPath/UnityCache；刷新 __info 最后使用时间；在 AssetBundleLoader.Awake 原逻辑之前释放，早于过期设置和缓存查询。载荷字节不改动，继续使用 Unity 原生校验及加载流程。
