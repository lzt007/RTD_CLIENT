# 显示翻译插件与中文位图字体

## 翻译数据

把 RTD_TRANSLATION 导出的 UTF-8 JSON 对象复制到 `paths.translation`（默认 `inputs/localization/translation.json`），例如 `{"原文":"中文"}`。逐字符精确匹配，不trim源文本；空或纯空白译文忽略。同源重复键拒绝，非字符串、损坏JSON、非法UTF-8整份回退空字典。文件缺失不阻止客户端继续显示原文。请通过翻译项目导出器检查占位符、NGUI颜色/符号标签；不要手动破坏 `{0}`、`{1:000}`。

默认映射嵌入生成的 RTDLocalization.dll 的字节数据，同时 APK 内可查看 `assets/rtd-localization/translation.json`。运行时读取优先级：`Application.persistentDataPath + "/rtd-localization/translation.json"` 若存在则覆盖嵌入版；损坏的外置文件回退空字典，不暗中回退旧表。font.png/font.tsv 也按同目录文件优先、缺失使用嵌入版；所有文件只尝试加载一次，不每帧轮询。应用目录具体绝对路径由 Unity 决定，未在新环境上断言某个 Android 固定路径。放置外置文件后需完整重启客户端。

UILabel.ProcessText 读取原mText之后、Replace/测量/换行之前映射显示值，不改mText、mLastText或text getter。密码和 UIInput 初始化找到的输入标签保持原文。普通标签只在命中译文且字体覆盖所有字形时切到可选字体；未翻译标签保留原字体。

模板只处理静态验证第一参数来自 GameText.Get 的 String.Format 调用，改到同签名RTDLocalization.Format。wrapper在格式化前查表，格式化后检查全部字形，缺字/译文格式错误则使用原模板结果。首次模板显示可主动寻找已加载 UIFont 材质并初始化字体；若此时没有可用UIFont，保留原文，不阻塞启动。GameText业务getter完全不修改。当前不覆盖其他业务字符串、任意拼接、原生弹窗、HTML、图片文字或全部动态界面。

## 可选字体注入

**原字库未证明有简体中文字形；只给译文表不会自动显示中文。** Git默认不带font.png/font.tsv，缺字体时插件保留原文。本机拆分副本额外生成了101字形的演示PNG/TSV（ASCII与“中文示例字体”），仅ignored本地资源，不代表覆盖翻译字表；新增译文需按授权字体重新生成。提供两份资源后重新构建即可嵌入；也可在应用持久目录提供覆盖。加载器创建共享UIFont/BMFont，复制旧材质和shader并替换纹理，按表创建字形。PNG建议白色RGB+alpha字形，单页图集；不能只放TTF，更不能假设旧Unity提供动态字体。

TSV严格为制表符分隔。首行4整数：`charSize baseOffset textureWidth textureHeight`。后续每行8整数：`Unicode码点 x y width height offsetX offsetY advance`，以PNG左上原点像素坐标，PNG尺寸须匹配首行。旧UTF16字体仅支持BMP。需要覆盖译文字集、原文保留字形、ASCII数字和参数可能带入的字符。缺任一字符则该显示/模板回退原文。NGUI图标符号与原kerning等没有自动迁移到此简化表，完整美术字体需扩展表与测试，不能将演示字库称为原字体等价替换。

可选脚本 `python scripts/make-font.py` 使用Pillow从 `paths.fontSource` 的TTF/TTC生成单页PNG/TSV，字号/图集尺寸由根配置font字段指定。它合并映射源文本、译文、ASCII和演示中文，并在超出单页时失败；不会自动生成多页。输入字体需自备合适授权。Windows字体可仅作本机演示，不要擅自分发；原文件不复制进Git。脚本的简化字形上对齐需要真机调整baseline、字号和换行，不是最终排版验收。

## 已测与未测

已测插件可针对原版mscorlib/UnityEngine编译；JSON解析、UTF8失败、空映射、字体缺失/注入、密码与输入标签保护、首次模板前初始化、动态缺字回退由源码测试替身验证。APK静态验证真实输出的IL钩子、业务getter不变、签名与原生补丁。

尚未安装/启动新APK；未验收Android实际PNG加载、shader alpha、字号基线、图标、长剧情布局、应用持久目录、GPU/CPU峰值或帧率。2048² RGBA纹理原始约16MiB，还可能保留CPU副本；不得以PNG压缩大小估计运行内存。本次建立可维护汉化入口，不宣称完成全部汉化。

部署翻译映射 `inputs/localization/translation.json` 被Git忽略，正式词条由RTD_TRANSLATION项目统一维护。首次构建若文件缺失，自动从 `examples/translation.example.json` 初始化空对象；之后把翻译项目导出文件复制到该路径即可。
